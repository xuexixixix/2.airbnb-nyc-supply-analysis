# 统计推断结果（短租型零评论率）

> 由 `scripts/05_inference.py` 生成。样本：短租型 `minimum_nights < 30`（n = 5,540）。
> 结论为观察性关联，不是因果推断。

## 一、描述性：各房型零评论率

| 房型 | n | 零评论数 | 零评论率 | Wilson 95% CI |
|---|---:|---:|---:|---|
| Entire home/apt | 1,685 | 159 | 9.4% | [8.1%, 10.9%] |
| Hotel room | 499 | 385 | 77.2% | [73.3%, 80.6%] |
| Private room | 3,314 | 809 | 24.4% | [23.0%, 25.9%] |
| Shared room | 42 | 3 | 7.1% | [2.5%, 19.0%] |

## 二、卡方检验：房型 × 零评论（未调整）

- chi2 = **962.1**，dof = 3，p < 0.001
- Cramér's V = **0.417**（中等偏强关联）

## 三、逻辑回归（主模型，排除 Hotel room）

- 样本量：**5,041**（短租型 5,540 − Hotel room 499）
- 伪 R² = **0.227**；AUC = **0.817**
- 房型联合检验：LR chi2 = **354.3**，dof = 2，p < 0.001

| 变量 | OR | 95% CI | p |
|---|---:|---|---:|
| 房型: Private room | 6.15 | [5.00, 7.57] | < 0.001 |
| 房型: Shared room | 6.17 | [1.83, 20.75] | 0.003 |
| 行政区: Bronx | 1.05 | [0.59, 1.85] | 0.872 |
| 行政区: Brooklyn | 0.59 | [0.46, 0.77] | < 0.001 |
| 行政区: Queens | 0.53 | [0.37, 0.76] | < 0.001 |
| 行政区: Staten Island | 1.31 | [0.54, 3.22] | 0.551 |
| 房东规模: 2-5 | 1.01 | [0.76, 1.33] | 0.959 |
| 房东规模: 6-19 | 1.82 | [1.36, 2.45] | < 0.001 |
| 房东规模: 20+ | 3.56 | [2.60, 4.87] | < 0.001 |
| 持证: 已豁免 | 5.17 | [3.75, 7.13] | < 0.001 |

- 最大 VIF = **3.19**（< 5，无严重共线性）

## 五、稳健性：全房型（含 Hotel room）

- 样本量：5,540；伪 R² = 0.293
- Hotel room vs Entire：OR = **16.23**，95% CI [12.24, 21.53]，p < 0.001

> ⚠️ Hotel room 499 套全部为 Exempt，与持证状态高度共线。该 OR 不能干净地解释为房型效应，因此主模型排除 Hotel room。

## 六、结论

控制行政区、房东规模、持证状态后，房型与零评论率仍显著相关：
- Private vs Entire：OR = **6.15**，95% CI [5.00, 7.57]，p < 0.001
- 房型联合检验：LR chi2 = **354.3**，dof = 2，p < 0.001
- 模型区分度：AUC = **0.817**
- Shared room n = 42，CI [1.83, 20.75] 很宽，**不作结论**
- Hotel room 与 license 共线，只报告描述性 77.2%，不报告调整后 OR
