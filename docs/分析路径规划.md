# 分析路径规划

> 本项目基于「数据集画像」定制，**非通用模板**。
> 每个阶段的侧重点由数据类型（特征数据 + 事件表）与目标岗位（大厂 DA / 运营）共同决定。
>
> **编号说明**：本文件已于 2026-10-03 从旧的 10 阶段对齐到 12 阶段工作流。

---

## 数据集画像诊断

| 维度 | 结论 |
|------|------|
| **数据灵魂** | 特征数据为主（`listings` 一行一房源）+ 事件表配套（`calendar` / `reviews`） |
| **核心维度** | 用户（房东）✅ / 地理 ✅ / 时间属性 ✅ / 多表关系 ✅ |
| **业务场景** | 共享经济平台 · **供给侧运营** |
| **数据规模** | listings 30,259 · calendar 11,152,576 · reviews 990,170 · 4 表可 Join |
| **匹配的能力方向** | 商业洞察导向、沟通落地导向 —— 不以刷模型分数为目标 |

## 核心叙事（已实证）

项目初期预判了三个可能的叙事，目前进度：

| # | 叙事 | 状态 | 证据 |
|---|------|------|------|
| 1 | **平台不缺供给，缺的是有效供给** | ✅ **已实证** | 44.1%（13,332 套）房源「开门但没客」<br>22.4%（6,791 套）未来一年完全不可订 |
| 2 | **房东专业化** | ✅ **已实证** | 0.56% 的房东（93 人）控制 21.6% 的房源<br>单个房东最多挂 955 套 |
| 3 | **监管套利** | 🚧 待展开 | 82.5% 的房源无短租许可证（`license` 字段） |

| 房东规模分层 | ✅ 保留 | 改用 `calculated_host_listings_count`（100% 非空） |
| 房东响应度分析 | ❌ 取消 | `host_response_rate` / `acceptance_rate` 全空，无替代 |
| 即时预订策略分析 | ❌ 取消 | `instant_bookable` 全空，无替代 |
| 逐日价格分析 | ❌ 取消 | `calendar` 表本快照无 `price` 列 |
