## 预判的核心叙事

好项目需要一个面试官能记住的钩子。本数据集大概率藏着以下三类反直觉发现之一：

1. **「平台不缺供给，缺的是有效供给」**
   大量房源常年不可订，账面供给虚高

2. **「房东专业化」**
   少数房东控制大量房源，个体房东正在被挤出

3. **「监管套利」**
   某些行政区 / 街区的房源呈异常聚集

> 三者均为**供给侧运营**的核心议题。实际发现以数据为准，此处仅为方向预判。
