> 本表是项目所有对外数字的**单一事实源**。
> README、报告、面试材料引用数字时，以本表为准。

---

## 一、口径约定

1. **长租 / 短租**：`minimum_nights >= 30` 为长租型，`< 30` 为短租型。
   `minimum_nights` 缺失的 **2 条**不归入任何一类，单列「缺失」。
2. **无记录**：`license IS NULL`；`Exempt` 为「已豁免」；其余为「有执照」。
3. **零评论率**：`number_of_reviews_ltm = 0` 的房源占该组房源的比例。
4. **零收入**：`estimated_revenue_l365d = 0` **或缺失**。
5. **极差**：`max(分组零评论率) − min(分组零评论率)`，单位百分点（pp）。
   引用时必须注明是「全样本」还是「短租内部」。
6. **生命周期**：活跃 = `number_of_reviews_ltm > 0`；
   僵尸 = `number_of_reviews = 0`；沉寂 = 其余。
7. **出租率**：评论数反推的估算值，只用于相对比较，不报告绝对值。

## 五、维护规则

1. **改口径先改本表**，再同步 README、报告、SQL 注释。
2. 引用极差时必须带「全样本 / 短租内部」限定语。
3. 引用 94.9% 时必须写明「无记录组」分母。
4. 缺失值不默认归类；比率的分母必须显式写出。
5. 任何新数字进入 README 前，先在本表登记公式与来源。
