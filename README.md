# NYC Airbnb 供给侧分析

> 从 3 万套房源档案与 700 万条日历记录中，拆解共享短租平台的**供给结构、定价逻辑与区域失衡**。

**分析视角**：供给侧运营 &nbsp;|&nbsp; **数据类型**：特征数据为主 + 事件表配套 &nbsp;|&nbsp; **规模**：4 表可 Join

---

## 🎯 业务问题

共享短租平台的运营，每天面对三个问题：

1. **平台上的供给是真实的吗？** —— 挂牌房源 ≠ 有效供给
2. **定价是市场行为，还是房东拍脑袋？**
3. **供给在地理上是否失衡？** —— 哪些街区供给过剩，哪些严重不足

本项目用公开发布的房源快照数据回答这三个问题。

### 复现方式

```bash

#    需要这 4 个文件：
#      listings.csv.gz          房源档案（一行一房源）

# 2. 安装依赖
pip install -r requirements.txt

# 3. 建表并导入数据库（详见 sql/README.md）
```

## 🔬 方法论亮点

本项目在数据口径上做过三处关键处理，均记录在 [`docs/`](docs/)：

### 1. 识别出「不可用 ≠ 已出租」

`calendar.available = f` 混合了**真实预订**和**房东主动封锁**两类完全相反的情况，
直接当出租率计算会系统性高估需求。

→ 详见 [`docs/方法论_出租率估算.md`](docs/方法论_出租率估算.md)

### 2. 采用公开可溯源的方法论

出租率改用 Inside Airbnb 官方公布的 **San Francisco Model**，基于评论数反推，
并对 4 种估算方法做敏感性对比，验证结论稳健性。

### 3. 公开指标口径与局限

见本文末「局限说明」章节。

## ⚠️ 局限说明

- **出租率为估算值**：平台不公开订单数据，本项目的出租率基于评论数反推，
  仅在**同类型房源内部**具备可比性，**不可作为绝对值引用**。
- **日历仅含未来日期**：`calendar.csv` 不包含历史，无法直接观测过去的实际入住情况。
- **评论率存在系统性偏差**：独立研究显示真实评论率约 55%（本项目采用保守的 50%），
  且价格越高、预订越频繁的房源评论率越低 —— 该偏差方向与部分分析口径一致，
  可能放大跨类型对比的差异。
- **快照数据**：所有指标基于单次快照，不能反映时间趋势。
